# 멀티테넌트 쇼핑몰 - 웹 콘솔 (프론트엔드)

빌드 도구 없이 **순수 HTML/CSS/JS** 로 만든 관리/쇼핑 콘솔입니다.
Node 설치가 필요 없고, 로컬의 Python 정적 서버로 띄워 크롬에서 EC2 백엔드에 접속합니다.

## 실행 방법

### 1) 정적 서버 띄우기
`start-frontend.bat` 더블클릭 (또는 PowerShell):
```powershell
cd C:\3rdProject\shoptest\frontend
python -m http.server 5173
```
> 포트 **5173** 사용 — 백엔드 CORS(`localhost:5173`)가 이미 허용되어 있어 별도 설정이 필요 없습니다.

### 2) 브라우저 접속
크롬에서 **http://localhost:5173** 열기.

### 3) 로그인
- **서버 주소**: EC2 퍼블릭 IP. 예) `http://<EC2-퍼블릭IP>:8080`
  (재시작으로 IP가 바뀌었으면 콘솔에서 확인 후 입력. 로그인 화면 "서버 상태 확인" 으로 연결 테스트 가능)
- **아이디 / 비밀번호**: 부트스트랩 관리자 계정 (`.env`의 `ADMIN_USERNAME` / `ADMIN_PASSWORD`)

서버 주소는 브라우저(localStorage)에 저장되며, 로그인 후 상단바의 주소 칩을 눌러 언제든 변경할 수 있습니다.

## 역할별 화면
| 역할 | 사용 가능 화면 |
|---|---|
| `super_admin` | 대시보드 · 테넌트(생성/수정/활성/삭제) · 사용자(생성/삭제) · 감사로그 · 각 테넌트의 상품/주문 관리 |
| `admin` | 대시보드 · 소속 테넌트 상품/주문 관리 |
| `customer` | 쇼핑(상품 담기/주문) · 내 주문 |

## 전체 흐름 테스트 시나리오
1. 슈퍼관리자(super_admin) 로그인 → **테넌트** 생성
2. 그 테넌트의 **상품** 등록
3. **사용자**에서 role=`customer`, 소속=그 테넌트로 고객 생성
4. 로그아웃 → 고객으로 로그인 → **쇼핑**에서 주문
5. 다시 super_admin → 해당 테넌트 **주문**에서 상태를 `paid`/`shipped` 로 변경
6. **감사로그**에서 활동 확인

## 사전 조건 (백엔드)
- EC2 백엔드 8080 기동 중
- 보안그룹 8080 인바운드에 **내 PC IP** 허용 (IP 바뀌면 AWS 콘솔에서 갱신)
- HTTP(비 HTTPS) 통신 — 로컬 페이지도 http 이므로 혼합콘텐츠 문제 없음
